## 3. 三端责任与不得上传的内容

| 范围 | 应调整 | 不应迁入 |
|---|---|---|
| 客户端 | 理解与计划展示、本地工具、文件范围、分支、流式对话、取消、浏览器/密码库、更新器 | 供应商API Key、发布签名私钥 |
| 平台服务端/总控 | 认证、模型代理、通用规划协议、任务事件/恢复、并发计费、版本发布和兼容性、脱敏运维 | 用户网站密码/Cookie、完整浏览器Profile、原始Word/Excel/PDF、默认全部项目历史 |
| GitHub平台仓库 | 经筛选源代码、测试、空白模板、依赖锁、CI、部署和迁移脚本、签名发布流程 | 客户文件、运行目录、数据库、真实环境变量、密码、私钥、业务模板残留数据 |
| GitHub Releases/受控下载源 | 已验收版本包、签名清单、校验值、版本说明 | 客户业务数据和本机凭据；私有仓库下载令牌不得嵌入客户端 |
| OA仓库/服务 | 优先不改；先浏览器走原有流程，只有已证实缺失的必要接口才单列范围 | 平台专用浏览器核心、平台用户密码库、绕过OA权限的接口 |

浏览器操作执行在客户电脑；云端模型只接收任务所需且脱敏后的有限观察。服务器不托管用户已登录浏览器，也不暴露通用远程shell/JavaScript执行接口。OA前后端地址只是站点适配信息，不是平台API地址。

保持现有业务红线：原件默认只读；批注经同意写副本；隐藏表格任何内容不参与审核或外发；锁定模板/Excel链接不可改；业务资料、成果、缓存不默认放C盘；本地Skill可离线用，模型调用前联网验证；用户只看余额，不显示Token和收费明细；API Key仅服务端保存。浏览器上传仅明确授权的验证成果副本，不绕过原件外发限制。
