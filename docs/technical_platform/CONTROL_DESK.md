# 独立 Web 总控服务台

本地 Demo 第一版。入口为 `/admin`，不是客户端内嵌页面；复用同一服务端与管理员权限。
采用原生语义 HTML、独立 CSS/JavaScript，无 CDN、外部字体或 Node 构建依赖。

## 本地启动

在仓库根目录使用 cmd，先按现有服务端配置设置数据库、JWT密钥和供应商加密密钥。
已有数据库必须沿用原密钥，不能临时更换，否则会影响已有会话或渠道解密。
不要把真实密钥提交到仓库。初次管理员初始化使用 `scripts/bootstrap_report_review_admin.py`，
先运行该脚本的 `--help` 查看参数，使用独立管理员账号，不与客户账号混用。

```bat
.venv\Scripts\python.exe scripts\run_control_desk.py
```

浏览器访问 `http://127.0.0.1:8800/admin`。默认仅监听回环地址。
如果同一服务端已经在运行，直接访问其 `/admin`，不要重复启动。
这不是公网部署脚本；非本机访问须由部署层提供HTTPS和访问控制。
未配置环境变量时现有服务端使用开发默认配置，只能用于隔离的本地测试，不能录入生产密钥。

## 已接通

- 管理员登录、退出、手动刷新；令牌仅保留在页面内存，刷新/过期后重新登录。
- 管理员专属账号、余额、模型、渠道概览；普通用户请求返回403。
- 创建客户账号、重置临时密码、调整余额（支持负数）、用户倍率。
- 新增模型、渠道、五类Token单价；渠道密钥服务端加密，不回显密钥和密文。
- DOM文本渲染、不使用innerHTML；静态资源CSP、禁止嵌入、禁止缓存。
- 表单重复点击保护；网络异常后的写入不自动重试，必须核对结果。

## 验收边界

当前不是完整总控交付：账号启停/独立踢线、流水与成本明细、模型渠道编辑停用、
完整操作审计、任务运维、Skill审批发布回滚仍待实现。
已有余额接口未提供请求幂等键，网络结果不确定时禁止直接重复充值。
前端不保存refresh token，不自动续期；当前管理员临时密码须通过既有认证入口修改。
尚未完成真实浏览器交互和视觉验收、真实API以及公网安全验收。

供应商密钥输入时仍会存在于管理员浏览器内存；不承诺能防御被入侵的管理终端。
客户程序不接触供应商密钥。独立Web入口不等于独立主机或独立安全域，部署时应限制管理入口访问。
