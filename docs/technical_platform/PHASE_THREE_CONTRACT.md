1. 包契约和只读检查：清单版本、Skill ID/版本、适配器、能力、依赖、文件哈希；
   拒绝路径穿越、脚本、符号链接、重复文件及超限压缩包。此轮已实现检查模块，未接入安装 UI。
2. 持久安装管理：经用户确认后安装，按 ID/版本隔离，安装记录与哈希可查；
   支持启用/停用及版本切换，不覆盖活动任务所使用的版本。管理服务及客户端管理入口已实现。
3. 运行接入：下拉列表显示可用 Skill；任务快照固定包版本/哈希；
   执行前复核内容、依赖及能力，不以包声明替代用户授权。未实施。
4. 工具能力门禁：当前只支持受控只读预检/审核适配器；模型调用仍走服务端认证、余额检查。
   后续写作/批注能力必须注册受控工具并经过单独明确授权，不能导入脚本自动获取权限。未实施。
5. 管理界面及验收：安装、状态/缺失依赖、启用版本、停用和回滚路径；
   本地回归及界面验证完成后，与第二阶段共同打包并做启动、规则一致性及端到端验收。未实施。

## 初版包格式

ZIP 内必须包含 manifest.json 和 UTF-8 SKILL.md，附加资源仅允许 md/txt/json。
manifest.json 严格字段：schema_version=1、id、version（数字三段式）、name、
adapter（report.review 或 review.preflight）、capabilities、dependencies、files。
files 为资源相对路径到 SHA256 的映射，不包含 manifest.json 本身。
dependencies 为 Python 发行包名称到版本范围的映射；只检查，不执行 pip，不导入包代码。
包大小上限 2 MiB，展开总量上限 4 MiB，最多 32 个文件，SKILL.md 最多 32000 字符。
哈希用于完整性检查，不代表可信发布者签名。资源检查通过也不代表已授权执行。

## 持久安装管理轮

SkillInstallation 将原始包 BLOB、哈希、版本元数据放入同一 SQLite 事务，不解压或执行代码。
包和启用状态按账号隔离；安装默认停用，同 ID/版本不同内容拒绝覆盖，同一原始包重复安装幂等。
启用、停用需 confirmed=True；切换时重新检查完整性和实际依赖版本，失败回滚保留旧启用版本。
queued/running/validating/interrupted 的相关任务均阻止切换及停用；interrupted 保守要求先核对，
不自动认为已结束。旧包保留以便回退；安装/启用/停用记录写入审计事件表。
说明：目前只有管理服务与测试，未自动安装用户包，也未将外部 Skill 接入实际任务运行。
安装列表不等同可执行授权。运行时任务版本固定与并发切换门禁仍须在后续接入中补齐。

## 客户端安装入口（后续更新）

用户明确允许客户端安装外部 Skill 后，增加侧栏“外部 Skill 管理”模态窗口。
支持选择本地 ZIP、预览名称/版本/适配器/能力/依赖/哈希、默认否的确认安装、启用及停用。
界面以纯文本展示外部元数据，安装时再次校验与确认时相同的包哈希；安装后默认停用。
沿用 Qt 控件与现有风格，清晰区分安装和运行状态；当前明确标注“尚未接入任务执行”。
当前窗口有任务时禁止打开管理入口，管理服务仍核对其他相关活动任务。
平台 91 项测试通过，含界面操作及包替换校验；EXE 尚未打包，运行接入仍待实施。
