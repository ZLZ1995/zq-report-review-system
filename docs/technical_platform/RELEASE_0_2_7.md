# ZQ Workspace 0.2.7 发布说明

## 交付范围

- 客户端版本 `0.2.7`，本地数据架构 `11`，服务协议 `1`。
- 增加用户、项目、会话三层本地记忆；记忆须明确确认，可查看来源、版本和状态并随时撤回。
- 审核问题增加稳定指纹、证据引用、精确去重和跨轮次 `new/persistent/resolved` 状态。
- 服务端增加 Skill 版本草稿、批准、稳定、撤回和回滚治理，所有写操作仅管理员可用并留审计记录。
- 增加签名在线更新：稳定发布检测、非系统盘暂存、包摘要与 Ed25519 签名复验、历史数据库完整清单、独立更新器、候选进程健康检查和失败不切换。
- 交付普通更新包以及包含稳定启动器、独立更新器和初始化状态的托管接管包。0.2.6 及更早的非托管客户端须先使用托管接管包一次，之后才能使用内置在线更新。

## 边界与未完成项

- 本发布使用应用级 Ed25519 包签名，不等于 Windows Authenticode 代码签名。
- 尚无独立干净 Windows 测试机；本机 Office/WPS 可用性和打包启动已验证，但全新机器安装、系统兼容矩阵和无缓存升级仍需外部实机验收。
- 0.2.6 的旧更新器不支持数据架构 10→11 切换，因此不对其提供静默在线升级；托管接管包保留原有项目目录和历史数据指针。
