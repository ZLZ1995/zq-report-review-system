# 财务简报

## 先确定交付形态

用户提供的模板或截图优先，已确认的样式不再重复询问。评估报告中的“企业近两年和评估基准日简要财务数据”使用单页简表，金额万元、两位小数。明确请求经营分析时才另行扩展。

`assets/financial_table.docx` 为本次用户截图确认后的版式参考。它含示例数据，必须由脚本覆盖全部数据、期间、来源注释和页眉页脚。不可直接交付资产文件，不把其中机构名推广为所有项目的默认机构。

## 快速执行

1. 读取用户明确提供的文件；中文路径通过 UTF-8 JSON 配置传入 bundled Python，使用 bash 或 cmd 启动 ASCII 脚本。不要扫描整个磁盘。
2. 使用 `scripts/run_brief.py config.json`，一次执行暂存、提取、校核、DOCX 回填、Word PDF 导出和 PNG 渲染。运行前用工作区依赖工具取得 Python 与 Poppler 路径，按 documents 技能要求记录文档生成操作。
3. 此 Windows 环境已验证 Word COM 可导出 PDF，脚本使用独立 Word 实例。优先复用该路径，不重新探测缺失的 LibreOffice。其他环境若 Word 不可用则使用已配置的打包版渲染器；失败保留错误和日志，不声明通过。
4. 查看生成的所有页面图，确认单页、标题与表格同页、无截断、正确期间和单位。只有版面不合格才重排重渲染。
5. 在 `timing.json` 记录人工视觉校验完成时间，明确区分机器执行耗时、包含视觉检查的复跑耗时与技能开发耗时。没有同口径历史记录时，不宣称提速百分比。

## 取数约束

- 资产负债表选“期末余额”，利润表选“本年金额”；匹配标签和表头，不依赖固定列号。本期月份金额不可代替年度累计。
- 利润总额和净利润独立取数；缺值、重复匹配或公式缓存为空须报错，不能补零。
- 验证编制单位和报表日期与配置一致；年度利润与半年利润列明实际期间，不年化、不混用3月和6月。
- 金额先用元核对资产等于负债加权益，再转换万元；源为数值零才填零。低于0.005万元的非零数在附注说明，防止误解。
- `extraction.json` 保留原始文件、sheet、坐标、原值及校验记录；源文件散列前后须一致。
- 审计机构、文号、审计意见只能来自已核实审计资料。普通 Excel 数据来源写企业提供的财务报表。

## 配置

UTF-8 JSON 字段：`company`、`output_dir`（新建 ASCII 运行目录）、`template`（可选）、`footer_org`（可选）、`report_header`（可选）、`poppler`（pdftoppm.exe 绝对路径）、`sources`。

`sources` 为按时间排序的三项，每项含 `path`、`date`（YYYY-MM-DD）、`balance_label`、`income_label`。前两项为两个完整会计年度末，第三项为基准日。输出 `financial_brief.docx`、内部校验用 PDF/PNG、`extraction.json`、`timing.json`。仅交付 Word 及用户要求的计时记录。
