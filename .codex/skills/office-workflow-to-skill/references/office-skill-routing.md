# 办公技能协同路由

## 路由表

| 场景 | 主技能 | 交接与最低验收 |
| --- | --- | --- |
| 撰写文案或报告并交付 DOCX | `documents` | 传入已确认的内容结构、模板与来源；生成后渲染全部页面并逐页检查 |
| 填写、生成或分析 Excel | `spreadsheets` | 传入字段、公式、来源与口径；重算、检查关键值和公式、扫描错误、渲染相关工作表 |
| 制作或修改 PPTX | `presentations` | 传入受众、页数、叙事、模板与素材；检查可编辑性并渲染全部幻灯片 |
| 读取或生成 PDF | `pdf` | 文本抽取不得代替版面核验；最终 PDF 重新打开并逐页渲染检查 |
| PDF/扫描件生成 Word 报告 | `pdf` -> `documents` | PDF 负责完整读取和页级视觉核对，documents 负责报告生成和最终 DOCX 渲染 |
| Excel 数据生成 PPT | `spreadsheets` -> `presentations` | Excel 负责口径、计算和核对，presentations 只接收已验证的数据与来源 |
| PDF 数据填入 Excel | `pdf` -> `spreadsheets` | 保留页码/表格来源线索，Excel 负责类型、公式、重算与工作表视觉验收 |
| 图片文字生成报告 | 视觉读取/OCR -> `documents` | 对低置信度文字逐项确认；documents 负责成文、模板和 DOCX 验收；需要 PDF 时再调用 `pdf` |

## 编排规则

1. 先确定最终交付格式，再确定主技能；来源格式通常决定前置技能。
2. 每个技能只负责其擅长的边界。不得让 PPT 技能承担 Excel 口径计算，也不得仅靠 PDF 文本抽取判断版式。
3. 技能之间传递结构化中间结果，至少保留来源文件、页码或工作表、字段/单元格位置和处理说明。
4. 使用模板时，模板优先于通用默认值；先确认哪些版式、公式、母版或原生特性必须保留。
5. 同一流程包含多个交付文件时，分别指定责任技能和验收标准。
6. 调用具体办公技能前，完整读取该技能及其本次任务要求的引用文件。若技能版本变化，以当前安装版本为准。

## 失败与回退

- 关键数据缺失：列出具体字段或页面，询问补充或用户认可的替代方案。
- 来源冲突：展示冲突位置和候选值，请用户指定权威来源。
- 模板能力不兼容：说明不能保留的原生特性，先与用户约定可接受方案。
- 无法提取文字：指出页码或图片，优先请求更清晰文件或人工确认，不猜写。
- 试跑未通过：保留失败证据，修正规则或实现后重新执行相关技能验收。
