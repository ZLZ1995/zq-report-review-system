# 0.2.6 修复说明

现象：资料识别后任务失败；停止按钮无法中断网络等待。

根因及证据：客户端任务 85385bd15a714a6a8d1492059f97adf1 在执行阶段记录 RemoteAuthenticationError，运行目录为空。对应云端日志请求路径为 /api/v1/api/v1/material-analysis，返回 404；并非模板填报校验失败。停止仅设置 Event，原网络等待循环未检查取消。

修改：资料识别改用统一客户端业务方法，路径仅拼接一次。只读解析和网络等待支持取消；取消后不接收迟到结果、不继续本地生成，任务记录为 cancelled。服务端新增归属校验的 review-jobs/{id}/cancel 接口，排队任务不执行，运行任务在当前模型调用结束后停止后续批次，按已发生用量结算。断网时无法保证取消请求抵达服务器，不承诺零费用或立即终止供应商调用。

验证：362 项全量回归通过，另补阻塞轮询取消测试通过。已覆盖单 API 前缀、未发请求前取消、阻塞请求取消、服务端排队取消及运行中不再调用第二批。

限制：未使用客户账号重新发起付费模型请求。资料识别修复不扩大已支持的表格布局范围。

## 本轮送审范围隔离

证据：任务 a03fe4bc1cb143cc85078d1b10e2d443 要求审核评估明细表与报告初稿，但快照包含了此前的财务报表及两份银行资料，共 5 个文件。文件列表刷新原先会自动勾选项目内每个文件名的最新版本，而非保留本轮选择。

修复：刷新保留手动选择；打开会话不自动选择历史附件；提交任务后的新上传开启新的选定范围，同轮多次上传累加，同名新版本替换旧版本选择，重复附件可明确重新选入。审核前展示完整送审清单并由用户确认，取消不会创建任务。实际送审清单记录到对话。历史文件保留，不删除，不通过解析自然语言猜测隐含的资料范围。

发布状态：原路径 EXE 打包遇到 WinError 5（拒绝访问），尚未完成此次修复的 EXE 替换或云端发布。

最终回归：technical_platform、report_review_app、report_review_server 共 365 项测试通过；新增了历史附件默认不选、刷新保持范围、重复附件重新选入、同轮累加与跨轮隔离、新会话隔离、取消送审确认不创建任务等断言。保留 1 项第三方 FastAPI/Starlette 弃用警告。未执行真实付费模型复测。

## 追加：对话路由与审核后批注

- 删除手动 Skill 选择下拉框。用户提交后，由 `/api/v1/skill-route` 进行鉴权、计费及模型意图判断，成功后进入既有权限和文件范围门禁；不明确的任务追问，不使用默认审核兜底。仅发送本轮指令和已启用 Skill 的用途摘要，不发送项目历史附件内容或路径。路由等待可取消，取消后不启动业务执行。
- 内置四种执行能力及已启用、依赖满足的外部只读适配器进入候选目录。外部包的版本和哈希写入任务快照，执行前再次核验启用状态。只复用受支持适配器，不执行包内任意脚本、不授予原件修改权限。
- 完整审核有问题时，每轮询问一次是否生成标记及批注副本；暂不生成后不重复询问，历史会话保留入口。用户确认问题及保存目录后才生成副本。无问题、取消或失败不触发生成。
- DOCX 仅标注唯一匹配、无复杂对象的完整正文段落；Excel 仅标注原文匹配的可见单元格。黄色标记与批注不更改文字、数值、公式。非目标 ZIP 部件逐项校验保持原字节，隐藏工作表不参与定位，xlsm 保留原扩展名及宏部件。PDF、合并区域、无法可靠定位或无法兼容追加已有批注时跳过并记录原因。
- 批注文件在所选目录生成，不覆盖既有输出；对话保留成功/跳过清单及文件入口。批注工作使用后台线程，取消在文件边界生效。

验收边界：模型路由目前验证的是模拟响应、鉴权与白名单门禁，尚未进行真实付费模型语义复测。Word/Excel 副本通过结构与只读回读测试，尚未完成 Word/WPS 实机视觉验收。源码不等同于已发布版本：本轮尚未重建 EXE、推送 GitHub 或部署新增路由接口；需服务端和客户端配套发布。

追加最终验证：378 项完整回归通过，新增核心模块 Ruff 检查通过。期间既有 JSON 仓储测试曾遇到 Windows os.replace 的 WinError 5；未修改该业务逻辑，单项复跑与随后全量复跑通过。保留一项 FastAPI/Starlette 第三方弃用提示。

## 输入框快捷键

Enter/数字键盘 Enter 触发原有发送按钮；Alt+Enter 在光标处换行。快捷键仅作用于对话输入框，不改变登录等弹窗的回车行为。输入法预编辑状态和按键长按重复不触发发送；忙碌时沿用原有禁用逻辑。输入框及发送按钮提示同步更新。Qt 模拟输入法事件测试不等同于各厂商中文输入法实机验证。
