# 本地平台功能更新工程施工清单

## 0. 范围与不可越界项

- 本轮只更新本机客户端源码、本地构建物和独立本地验收安装目录。
- 不修改 GitHub 仓库、Zeabur 服务、总控服务端、在线发布记录及公开 Release。
- 业务资料与任务成果继续保存在用户明确选择的非系统盘项目目录。
- 平台数据固定保存在安装根目录的 `data/` 下；目录不可写时明确阻断，不静默回落到 C 盘。
- Skill 默认只读来源并生成副本；不得覆盖原件，不执行外部 ZIP 中的任意脚本。

## 1. L01 基线与施工隔离

目标：在独立分支和独立工作树施工，不污染稳定安装。

修改：记录当前提交、工作树、测试命令和本地安装目录。

验收：工作树无既有未提交修改；所有新改动可单独审阅；云端与发布版本不发生变化。

## 2. L02 平台数据目录

目标：浏览器按钮只负责显示或隐藏浏览器，不再要求用户选择数据目录。

修改：数据根目录固定为 `<安装根>/data`；账户数据位于其下的隔离目录；保留显式迁移能力但从常用界面移除目录选择。

验收：首次打开浏览器不出现文件夹选择框；可写安装目录正常启动；只读或缺失安装目录给出明确错误；项目资料路径不受影响。

## 3. L03 项目导航与操作

目标：项目级入口符合 Codex 式交互。

修改：移除逐条消息的“从此消息创建分支”；项目行提供改名入口和三点菜单；菜单包含置顶/取消置顶、归档、从侧栏移除；移除只删除本地索引登记，不删除项目目录或数据库。

验收：项目可改名并持久化；置顶顺序稳定；归档后可恢复；移除后业务文件哈希不变且可通过“打开已有项目”重新登记；既有分支会话仍可读取。

## 4. L04 统一 Skill 目录

目标：用户可以看到 Agent 当前具备的全部能力，但无需手动切换 Skill。

修改：统一列示内置 Skill、外部 Skill 和原生能力；显示版本、来源、状态、能力边界和依赖；外部 Skill 保留安装、启用和停用操作；内置能力不可被误停用。

验收：目录中至少显示报告审核、资料预检、评估明细表、工商历史沿革、财务简报、办公工作流转 Skill、浏览器能力；选择详情不泄露密钥或内部提示词全文。

## 5. L05 新 Skill 纳入内置能力

目标：整合 `office-workflow-to-skill` 与 `financial-brief-docx`。

修改：复制经确认的 Skill 规则、脚本和锁定模板；登记版本、契约、工具适配器和打包资源；模板文件按原哈希进入构建；财务简报在项目任务目录生成副本；办公工作流先生成并校验工作流契约，再生成待验收 Skill 包。

验收：开发态和冻结态均能发现资源；财务简报用三份合成财务报表完成 Word/PDF/PNG/JSON 验收；办公工作流契约能通过校验器且未确认契约不得安装；所有来源哈希不变。

## 6. L06 自然语言安装本地 Skill

目标：用户可在当前消息附加 ZIP，并用自然语言要求 Agent 安装。

修改：确定性识别明确安装意图；只绑定当前轮选中的单个 ZIP；先进行惰性解包检查、manifest/文件哈希/路径穿越/大小和依赖检查；展示确认摘要；确认后安装、注册并按用户选择启用；同 ID/版本/哈希实现幂等。

验收：无 ZIP、多个 ZIP、历史轮 ZIP、路径穿越、符号链接、未登记脚本、哈希不符均被阻断；取消确认不写入；重复安装相同包不产生重复版本；日志不输出 ZIP 内容中的秘密。

## 7. L07 Agent 路由与 Harness

目标：Agent 理解自然语言后自动选择能力，不显示手动 Skill 切换器。

修改：候选能力从真实注册表生成；路由结果绑定当前轮附件快照、Skill 版本、规则哈希、权限和验收门；Skill 安装、财务简报、办公工作流分别使用受信任适配器；执行前后复核来源与成果。

验收：新附件不会夹带旧轮附件；未授权不执行；计划与执行不一致被阻断；取消能停止受控子进程；失败只发布诊断或反馈文件，不冒充正式成果。

## 8. L08 界面与回归

目标：交互入口清晰且不破坏既有审核、生成、浏览器和更新功能。

修改：技能入口改名为“能力与 Skill”；项目菜单与键盘操作补齐；状态信息使用用户可理解的描述。

验收：目标 UI 测试、项目目录测试、Skill 安全测试、浏览器测试、生成器测试、完整 technical_platform 回归全部通过。

## 9. L09 本地构建与本地安装验收

目标：生成仅供本机验收的 EXE，并安装到独立目录。

修改：构建脚本纳入四个内置业务 Skill 及其锁定资源；生成目录版 EXE；复制到 `D:/ZQ-Acceptance/local-platform-install`（或等价独立目录），平台数据位于该安装根的 `data/`。

验收：EXE 启动、登录、项目打开、浏览器开关、技能目录、两项新 Skill 路由和成果交付通过；稳定安装目录和公开发布物未被替换。

## 11. 验收边界与后续人工检查

- 本轮仅生成独立本地验收安装，没有提交或推送 GitHub，没有触发 Zeabur 或公开 Release。
- 冻结版已在 Microsoft Word 路径实际生成并检视单页财务简报；WPS COM 回退代码已纳入，但本机没有独立 WPS-only 环境，需在相应机器上做最终手工验收。
- `office-workflow-to-skill` 在平台中负责自然语言入口和已确认工作流契约校验；后续产生的子 Skill 仍需单独证明运行和安装确认，不会绕过授权自动执行外部脚本。
- 权限模式只决定 Agent 何时请求批准；送审文件范围、生成资料角色、登录账号及上传成果选择等业务决策仍由用户明确指定。
