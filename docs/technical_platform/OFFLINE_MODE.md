# 本地运行与按需联网（取代旧的强制联网规则）

启动界面提供账号登录和“离线进入本地工作区（不调用模型）”；关闭启动界面仍退出。
离线进入不请求模型列表或余额，可导入、预检及查看离线工作区历史。
服务端 HTTPS 地址内置，用户无需输入；不启动全程心跳，不因断网关闭本地工作区。
点击“评估报告审核”执行时，未连接则要求登录。取消登录保留输入。
供应商API Key仍仅在服务端配置，每次审核任务通过鉴权接口、余额预检和预扣，不能离线调用模型。

本地审核规则随源码安装在 `technical_platform/review_rules.txt`，执行时读取，
记录到本地任务快照并随可见文本发送。服务端保留结构化协议、可见性校验和计费保护；
规则字符计入预扣估算。当前是内置审核Skill规则，不是任意第三方Skill安装器。

本地项目按所选数据目录保存；离线使用独立的 offline-local 空间，登录后使用真实账号空间。
切换账号清除旧对话和草稿，执行中禁止切换。离线资料不自动归入账号项目，需重新导入。
历史 local-preview 数据保留，不自动认领或删除；旧项目迁移入口待实现。
owner 只是应用层隔离，不是数据库及附件加密，有磁盘访问权限者仍可读取本地数据。

用户要求独立保存和传输为 user_request，并加入服务端每个审核批次及额度估算。
发布必须先更新服务端再更新客户端，旧服务端不识别该字段。
本轮未重建 EXE、未部署云端、未调用付费模型，真实端到端验收仍待完成。
