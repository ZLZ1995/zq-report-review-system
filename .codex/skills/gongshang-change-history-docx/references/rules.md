# 工商历史变更生成规则

## 事件筛选

- 按 `变更日期` 分组，同一日期作为一个事件候选。
- 仅保留有实质披露价值的事件。
- 删除仅有章程备案、股东顺序变化、重复其他变更的低价值事件。
- 法定代表人/法人代表变更必须披露，即使与其他事项同日发生。
- 事件编号按筛选后的保留事件重新编号。

## 事项过滤

- 默认不单独披露纯 `章程变更`，但若同日有核心事项，说明中可保留“章程变更”字样。
- `主要人员变更` 默认不进表，除非源数据明确同时写明 `法定代表人变更`、`法人代表变更` 或能从同日记录中直接定位到法定代表人字段变化。
- 仅因某个人员 `新增/退出`，不得自动推断 `法定代表人变更`。
- `其他变更` 若只是经营范围摘要或与核心事项重复，不进表；但人工口径可能要求在说明文字中保留“其他变更”。
- `股东变更` 若与 `股东出资变更` 重复，通常不另起表；人工口径可能要求在说明文字中保留。
- `经营范围变更` 与 `公司住所变更` 属于实质事项，应保留。

## 股权/出资实际变更判断

- 不要只因为 Excel 的 `变更事项` 写了 `股东出资变更` 就生成股权表。
- 解析 `变更前` 和 `变更后` 的股东名称、出资金额。
- 若股东集合、出资金额、持股比例都相同，仅顺序变化，则不披露股权变更。
- 有新增股东、退出股东、股东名称替换、出资金额变化、注册资本变化导致比例变化时，生成股权表。
- 若同日 `企业类型变更` 后为 `有限责任公司（法人独资）`，则 `变更后` 股东集合必须收敛为一个法人股东；若股权表仍表现为多个股东，必须视为事实冲突并停止交付，先回源核对。
- 若同日 `企业类型变更` 后为 `有限责任公司（自然人独资）`，则 `变更后` 股东集合必须收敛为一个自然人股东。

## 股权表格式

- 使用模板中的 7 列结构：
  - `项目`
  - `变更前`: 股东名称、出资金额（万元）、持股比例
  - `变更后`: 股东名称、出资金额（万元）、持股比例
- 每个股权持有人独立一行。
- 末尾必须有 `合计` 行。
- 金额合计分别汇总变更前和变更后出资金额。
- 持股比例合计有金额基础时为 `100.0000%`。

## 缺金额股权事件

仅在对应股东集合完全相同且相邻记录有明确金额时，允许以下继承。无后续金额证据时不得把退出股东金额依次分配给新股东；无法证明的金额应缺失并阻断正式交付。

- 如果 Excel 只有股东名称而没有金额：
  - 变更前金额/比例继承上一期有效股权结构。
  - 变更后金额/比例优先使用下一次有金额记录的变更前状态补全。
  - 左侧顺序按上一期有效股权表展示顺序。
  - 右侧顺序按本次或下一期可验证的变更后/下一期变更前顺序。

## 同日表格组织

- 同日有股权实际变更时，以 7 列股权表为主表。
- `注册资本变更`、`企业类型变更` 等短事项可追加到股权主表底部，而不是另起 3 列表。
- 同日无股权实际变更时，使用 3 列表：`项目 / 变更前 / 变更后`。
- 避免一个事件拆成多个孤立表，除非人工模板明确这么做。

## 文本和版式

- 字号和首行缩进遵守 `SKILL.md` 的“用户确认的文字格式”：正文小四、首行 2 字符；表格所有文字小五、首行 0。复制旧参考格式后仍须应用此规则。
- 描述句式采用：`（n）YYYY年M月D日，企业进行……，详情如下：`
- 有注册资本变化时，在说明中加入：`注册资本由X变更为Y`。
- 表格应为嵌入式正文表格，不得保留 Word 浮动定位属性 `w:tblpPr` 或重叠属性 `w:tblOverlap`。
- 跨页股权表应设置重复表头。
- 当人工校对版存在时，可复制其段落、表格网格、行高、字体等格式属性，但不要破坏单元格合并结构。

## 快照事实交叉核对

- 当同时拿到“企业当前信息截图/表”和“变更历史截图/表”时，必须先抽取当前快照事实：`法定代表人`、`企业类型`、`注册资本`。
- 任何历史沿革结尾总结都必须与当前快照一致；若不一致，优先判定为整理口径错误，不得直接交付。
- 当前快照中的 `法定代表人` 只能由明确的 `法定代表人变更` 链条或当前快照本身支撑，不得由 `主要人员变更` 代替推断。
