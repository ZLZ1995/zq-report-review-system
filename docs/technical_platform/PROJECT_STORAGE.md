# 项目目录与启动行为

正常启动不再要求全局业务数据目录：认证完成后打开账号的轻量项目位置索引。
系统应用目录只保存位置索引（账号、项目 ID/名称、数据库路径、上次项目/会话 ID），
不保存会话正文、附件、模型结果或安装包。认证凭据仍由原凭据机制处理。

新建项目时用户选定非系统盘目录，业务数据库位于目录的 .zq/platform.sqlite；
附件、会话、记忆、审核记录、Skill 包在该业务库及其相邻目录保存。
新目录不能覆盖已有 .zq 数据库。系统盘目录及指向系统盘的数据目录被拒绝。
正常打开已有数据库使用 SQLite mode=rw，缺失时不自动创建；不回退到 C 盘。
SQLite 临时数据使用内存；报告导出临时文件仍位于用户选择的输出目录。
保存报告对话框默认定位项目目录，正常项目模式拒绝系统盘输出。

旧工作空间通过“打开已有项目”登记当前账号拥有的项目，不移动文件，不改归属。
目录不可用会保留索引并提示，其他项目仍可打开。上次会话不存在时选择可用会话。
仅索引和业务数据分离，并不新增磁盘加密。共享 local-preview 数据仍不能自动归给登录账号。
开发测试显式 --data-dir 保留旧入口；普通双击启动不走该入口。

注意：不提供自动目录迁移；旧数据库中的绝对附件路径不会被擅自改写。
移动过旧工作空间后，若原附件路径失效，应恢复原目录位置或重新添加附件，历史记录保留。
外部 Skill 安装随当前项目业务数据库保存，空工作台需先创建或打开项目后再安装。

本轮仅源码修改，不自动更新 EXE 或云端，不修改真实业务文件。
